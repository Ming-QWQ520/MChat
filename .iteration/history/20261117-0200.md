## 一、LLM 层切回 openai-kotlin / Ktor

1. 依赖：`com.aallam.openai:openai-client:4.2.0`（Kotlin 2.0.20 元数据，与项目 Kotlin 2.0.21 兼容）+ `io.ktor:ktor-client-okhttp:3.0.3`；移除 okhttp-sse / Gson。
2. 新增 `OpenAiClientFactory`：按 providerId 缓存 OpenAI 实例（baseUrl+token 指纹失效重建）；`OpenAIHost(baseUrl)`（内部按 `trimEnd('/') + "/" + path` 拼接，兼容带/不带 /v1）；`Timeout(connect=60s, socket=300s)`；`LoggingConfig(LogLevel.None)`。
3. `ChatService` 重写：
   - `streamChat`：`openAI.chatCompletions(request)` Flow 逐事件映射为 `LlmStreamEvent`（Delta / Reasoning / ToolCallDelta / Usage / Done），**SSE 解析完全由库完成，无手写解析**；
   - `ChatDelta.reasoningContent` 为 openai-kotlin 原生字段（DeepSeek reasoning_content 直接可用）；
   - `Effort` 值类直传 DeepSeek 四档（none/low/high/max）；`FinishReason` 值类容忍非标准取值（insufficient_system_resource）；
   - `completeOnce` / `testConnection` 非流式；`fetchModels` OpenAI 兼容端点走 `openAI.models()`，Anthropic 风格端点 Ktor 直连（x-api-key + anthropic-version）；
   - 错误映射：`OpenAIAPIException.statusCode` 透传给 `LlmStreamEvent.Error`，`toLlmError` / `readableMessage` 保持调用方兼容。
4. `BalanceService` 迁移到 Ktor HttpClient（OkHttp 引擎，`AuxHttpClient`），kotlinx.serialization 解析。
5. 取舍：openai-kotlin 流式 Usage 仅 prompt/completion/total 三字段，`prompt_cache_hit_tokens` / `completion_tokens_details.reasoning_tokens` 明细在流式路径不再可见（库未暴露）；UI 展示不受影响，非流式路径不受影响。

## 二、UI 全面对齐 kelivo（第 5 轮 UI 重构）

1. **主题（core-theme）**：kelivo default 调色板（主色 #4D5C92 / 浅 #F7F7F7 / 深 #121213，动态取色保留）；`SurfaceLadder` 语义表面（page / card / surfaceFill / hairline / hairlineStrong，alphaBlend 推导）；排版对齐 kelivo（Medium/SemiBold 收敛，正文 16sp/1.65 行高）。
2. **动效（core-theme/Motion.kt）**：`MotionCurves`（EaseOutCubic / EaseInCubic / EaseInOutCubic / EaseOutQuart / EaseOutExpo 三次贝塞尔 + 按压 / 回弹弹簧）+ `MotionDurations` 五档（110/150/200/220/300ms）+ `animatePressScale`；全部 Kotlin/Compose 原生，尊重"减少动画"∪ 系统无障碍。
3. **液态玻璃（Fluxhub 用法）**：vendor `AndroidLiquidGlass` backdrop 库源码到 `core-backdrop` 模块（Kyant0，Apache-2.0），适配 Kotlin 2.0.21（LayerRecorder context 参数改显式参数）与 Compose 1.7.4（GraphicsLayer.record 补全 4 参签名、InverseLayerScope blendMode/colorFilter 去 override）；`GlassBackdropSource`（layerBackdrop 录制根内容）+ `Modifier.liquidGlass`（vibrancy + blur + lens 折射，Android 12/13 分级降级）+ `LiquidGlassSurface` 兼容旧签名。
4. **iOS 组件（core-theme/SectionCard.kt）**：`SectionCard`（12dp 圆角 + surfaceCard + 发丝描边）、`SectionHeader`（13sp semibold）、`IosDivider`（0.6dp / indent 54）、`IosNavRow`（36dp 图标槽 + 15sp Medium 标签 + 13sp 次级文本 + chevron，按压无涟漪 + 颜色 lerp）。
5. **长按锚点菜单（core-theme/Widgets.kt）**：`AnchoredContextMenu`——以长按点为水平中心；偏下（>55% 屏高）向上展开，偏上与中间默认向下；溢出自动换向 + 贴边；150ms EaseOutCubic 淡入 + 按压侧原点缩放；容器自带 animateContentSize；`Modifier.longPressAnchor`（onGloballyPositioned 换算根坐标）；Popup 父布局原点经 0 尺寸锚点测量换算。`AnchoredMenuItem`：44dp 行高 + 18dp 图标 + 14.5sp 文本 + danger 红色。
6. **聊天页（feature-chat）**：
   - 顶栏：菜单 + 用户 emoji + 标题（临时对话标识）+ 模型副标题 + 临时对话开关 + 新建；
   - 消息：用户右对齐 75% 屏宽磨砂/实底气泡 + 用户名/时间戳头部；助手左对齐气泡 + 思考折叠卡 + token 明细；

## 三、kelivo 功能移植（本轮 9 项）

1. 临时对话（temporary chat）：内存消息（负 id），不落库不生成标题，退出恢复原会话（feature-chat）
2. 会话复制（duplicate）：标题加"（副本）"，消息 + 附件行 + 附件文件一并复制（core-data + feature-chat）
3. 会话多选批量删除 / 批量置顶（selection mode）（feature-history）
4. 消息编辑后重发（edit & resend）：editAndTruncateAfter 删除后续消息（含附件文件）（feature-chat + core-data）
5. 快捷短语（quick phrases）：内置 6 条 + 自定义（DataStore），输入栏闪电展开（feature-chat + feature-settings）
6. 用户资料（user profile）：用户名 + emoji 头像（DataStore；抽屉 / 欢迎页 / 消息头部展示）
7. 滚动导航按钮（scroll nav buttons）：回到底部 / 上一条提问（feature-chat）
8. 气泡风格设置（frosted / solid，kelivo message style）（feature-settings + feature-chat）
9. 长按锚点菜单（消息 + 会话，自适应展开方向）（core-theme + feature-chat + feature-history）
