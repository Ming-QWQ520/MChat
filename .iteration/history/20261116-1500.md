### 一、UI 重构（DeepSeek 手机端风格）

依据用户上传的 DeepSeek 官方 APP 截图与本 APP 截图做视觉对比分析（VLM），
按「统一色板 / 弱化 AI 气泡 / 调试信息不进主聊天流」三原则重构：

1. **品牌配色体系**（core-theme/Theme.kt 全量重写）：
   - 三色法：品牌蓝 #4D6BFE（DeepSeek Blue）+ 中性灰背景（浅 #F7F7F8 / 深 #0F1014）
     + 内容色；删除默认 M3 紫，粉/橙/红杂色全部收敛为语义 token；
   - 深色模式输入容器 #1D1E24（对应 DeepSeek 端 #1E1E20）；
   - 排版：正文 16sp / 行高 1.65（长文阅读），标题字重收敛 Medium/SemiBold；
   - 启动器背景色同步品牌蓝（colors.xml）。
2. **消息列表**（feature-chat/components/MessageList.kt）：
   - 用户消息：右侧品牌蓝淡底气泡（primaryContainer），圆角 20/20/6/20；
   - 助手消息：扁平无气泡排版 + 28dp 圆角「M」徽标（DeepSeek 鲸鱼 logo 对应位置），
     token 明细弱化为浅色脚注；
   - Markdown 标题不再 maxLines=4 截断（修复截断成「会重枱」的问题）。
3. **输入区重构**（feature-chat/components/ChatInputArea.kt）：
   - 整体悬浮容器 28dp 大圆角 + 屏幕边距（DeepSeek 布局）；
   - 功能行内嵌：**当前模型名 chip**（点击切模型）、**上下文环**（30dp，环心显示
     上下文占用或 DeepSeek 余额，点击弹详情）、**深度思考三档 pill**（低/高/最高，
     模型不支持推理时禁用）；
   - 低余额提示条收纳进容器内（不再常驻遮挡正文）。
4. **空状态欢迎页**：居中 logo + 「你好，我能帮什么忙吗？」+ 副标题（DeepSeek 同款气质）。
5. **顶栏简化**：菜单 / 标题（可点击重命名）+ 副标题显示当前模型名 / 新建对话。

### 二、体验与缺陷修复

1. **流式输出滑动卡顿**（双重修复）：
   - ViewModel：网络 delta 高频到达时仅每 90ms 刷一次 UI（`UI_REFRESH_INTERVAL_MS`），
     避免逐 token 全量重组 + Markdown 重解析；
   - UI：自动跟随滚动改为「仅当用户停留在底部时」，上滑阅读历史不被打断；
   - token 估算改增量式（每个 delta 只做字符近似，O(1)），不再逐 token 全量重算。
2. **会话续接 bug**：新会话 id 未回写 UI 状态导致第二轮发送再次新建会话（历史断裂）。
   现在 `performSend` 创建会话后立即写回 `conversationId`，同一对话可持续多轮。
3. **token 估算修复**：
   - 流式中显示为「≈ N tokens」增量估算；服务端 usage 返回后以服务端为准；
   - 上下文环语义改为「下一轮请求的上下文占用」（server: prompt+completion；
     本地估算含系统提示词基线 160 + 图片基线 300/张）。
4. **图片背景**：设置 → 外观 → 聊天背景支持「图片」；选择后解码压缩（长边≤2048、
   JPEG 88）存私有目录，聊天页全屏显示 + 上下渐变遮罩保证可读性。
