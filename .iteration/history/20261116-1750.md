### 一、网络层重构：openai-kotlin → OkHttp + Gson 原生（core-llm 全量重写）

依据官方文档三页（api-docs.deepseek.com 首页 / thinking_mode / create-chat-completion）
与用户上传的《deepseekAPI调用示例.md》：

1. 依赖替换：移除 openai-client / ktor-*，引入 okhttp 4.12 + okhttp-sse 4.12 + gson 2.11
   （libs.versions.toml + core-llm/build.gradle.kts）。
2. 新增 DeepSeekModels.kt：ChatCompletionBody / ChatMessageBody（content 支持
   string | List<ContentPart>）/ StreamChunk / ChatUsage（prompt_cache_hit_tokens /
   prompt_cache_miss_tokens / completion_tokens_details.reasoning_tokens）/ ModelsListResponse /
   ApiErrorBody，全部 @SerializedName 蛇形映射。
3. 新增 LlmHttpClient：双客户端（default 60/120/60s 超时；sse readTimeout=0 无限读，
   思考模式长输出不被掐断），连接池复用。
4. ChatService 重写：
   - streamChat：EventSource 桥接 channelFlow；`data: [DONE]` 终止；usage 从最后一个
     chunk 捕获（onClosed 兜底防重复）；onFailure 读取 body 解析服务端 error.message；
     awaitClose 取消传播；
   - completeOnce / testConnection：非流式 OkHttp 调用，HttpLlmException 保留状态码；
   - fetchModels：GET /models，Bearer / Anthropic x-api-key 双认证，解析 data[].id。
5. ErrorCodeMapper（新增）：400/401/402/403/404/408/413/422/429/5xx → 中文描述 +
   服务端详情；网络异常分类（DNS/超时/SSL/连接拒绝）；finish_reason 语义化
   （length/content_filter/insufficient_system_resource/aborted）。
6. BalanceService 迁移到 OkHttp+Gson（移除 Ktor）。

### 三、多供应商系统（默认仅 DeepSeek）

1. DatabaseSeeder 重写：内置仅 DeepSeek（baseUrl=https://api.deepseek.com 不带 /v1）；
   模型 deepseek-flash（默认，视觉+思考，131072 ctx）/ deepseek-v4-pro（思考）。
2. 升级迁移：旧模型名 remap（deepseek-4.1-flash→deepseek-flash、deepseek-4.1-pro→
   deepseek-v4-pro、deepseek-chat/reasoner 同理）+ DataStore 默认模型名同步迁移；
   旧内置 openai/zhipu/grok 未配 Key 删除（会话 remapAllModels 整体迁到 DeepSeek）、
   已配 Key 转为自定义供应商保留。
3. 模型目录「删除不复活」：升级不自动补插内置模型；ProviderEditor 提供
   「恢复内置」按钮（restoreBuiltinModels）。
4. ProviderRepository 新增：createProvider（id 去重自动序号）/ upsertModel /
   deleteModel（同供应商优先 remap，跨供应商 remapProviderModel 同步 providerId）/
   deleteProviderCascade；ConversationDao 新增 remapProviderModel / remapAllModels
   （跨供应商迁移同时更新 providerId 与 modelId，修复会话挂错供应商的隐患）。
5. ModelConfigEntity 新增 isBuiltin 字段（DB v2→v3 迁移）；MessageEntity 新增
   reasoningContent 字段（思维链落库，历史消息可回看思考过程）。
